# 🚀 Oficina: Git e GitHub - Conceitos introdutórios e versionamento de código na prática

Bem-vindo(a) ao repositório oficial com os materiais da oficina **"Git e GitHub: Conceitos introdutórios e versionamento de código na prática"**, ministrada durante a Mostra de Ciência, Tecnologia de Cultura (Semana de Tecnologia) do IFSPB - Campus Santa Luzia.

## 📋 Sobre o Material

Este repositório contém os slides e recursos utilizados na oficina. O objetivo deste material é desmistificar o versionamento de código, ensinando desde os conceitos mais básicos até o fluxo de trabalho colaborativo utilizado no mercado de tecnologia.

## 📚 Resumo do Conteúdo

A oficina foi dividida em 4 blocos principais:

### 1. Conceitos Básicos
* O que é um Sistema de Controle de Versão (VCS).
* A diferença entre repositório local e remoto.
* Apresentação da diferença entre Git e Github.

### 2. Termos e Comandos Essenciais
O ciclo de vida do código (Modified, Staged, Committed) e os comandos do dia a dia.

### 3. Branches e Correções
* **Branches:** Criação de ramificações para trabalhar em novas funcionalidades de forma isolada e segura.
* **Merge:** Como unir o trabalho de diferentes branches.
* **Resolução de Conflitos:** O que fazer quando duas pessoas alteram a mesma linha de código.
* **Desfazendo erros:** A diferença entre `git reset` e `git revert`

### 4. Dicas Finais e Boas Práticas
* Diferentes formas de usar o Git (Terminal, GitHub Desktop, VS Code, Web).
* **Conventional Commits:** Padrões de mensagens de commit (ex: `feat:`, `fix:`, `docs:`) para facilitar a leitura e organização da equipe.
* **O GitHub como Vitrine:** Como usar o seu perfil como portfólio para se destacar no mercado de trabalho.
